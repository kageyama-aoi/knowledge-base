# ナレッジ整理提案（2026年1月以降ファイル対象）

作成日: 2026-03-11
対象: `pages/` および `pages/old/` 内の2026年以降ファイル（計約55ファイル）

---

## 現状の問題点

1. **md と html の二重管理** — `pages/old/*.md` と `pages/*.html` が同じ内容を別形式で存在している（自動変換の副産物）
2. **バージョン違いの重複** — `_2` サフィックスで全く同じ内容が複製されているファイルが複数ある
3. **テーマが近いのに別ファイル** — 同日・同テーマなのに分割されたファイルが散在している
4. **ファイル名と内容の不一致** — ファイル名から内容が想像できないファイルがある

---
